01 · HOW TO ASK

推荐提问公式

日常使用不需要记工具名。把下面几项说清楚，系统会选择对应能力；已经明确的条件不必反复说明。

入口@agent
+
证券001258 / 公司名
+
时间近三个月 / 2025年报
+
任务查日K / 分析Hurst
+
输出表格 / CSV
证券要明确

代码可写 001258 或 001258.SZ，也可写当前公司名。名称出现多个候选时按系统提示确认。

时间可用自然语言

日线、估值和 Quant 可说“近三个月”“近半年”“今年以来”“全历史”；明确日期可写起止日。

一次说一个主要任务

拉行情、跑 Quant、查财报是不同任务。复杂需求建议逐项提问，避免把多个数据口径混在一起。

系统答案保留源口径

空值保持未知，未查到记录不等于从未发生；不会为了好看擅自补零或换算单位。

系统会明确说明能力边界。无法完成时，不会用网页搜索、模型记忆或其他数据库路径偷偷补数。

暂未开放

Quant 图表与K线图

当前 Quant 只返回文字报告；候选图表代码不代表生产可用。

暂未开放

双证券、协整与配对

不比较两只证券的协整关系，也不生成配对交易结论。

暂未开放

选股、排名与推荐

不能回答“推荐5只最亮眼股票”，也不承诺收益或给出买卖建议。

暂未开放

回测与收益预测

不做策略回测、未来价格预测或复权总回报计算。

暂未开放

内部研报专用检索

来源与权限接口尚未接通；普通知识库中已有文档仍可按RAG检索。

当前财报是来源最新记录，不回答“截至过去某日当时已知的版本”。

05 · TROUBLESHOOTING

常见问题

为什么它说没有相关文档，或者没有调用数据库？

生产工作区默认是 Query 文档问答模式。数据库和计算任务需要以 @agent 开头，或点击输入框旁的 Start Agent Session。单凭模型一句“未挂载 Skill”不能判定服务故障。

为什么返回“未查到记录”？

未查到只代表本次条件下没有可展示记录，不等于停牌、零成交、从未发生或源数据不存在。先检查证券、时间和报告期是否正确。

为什么数值没有换成亿元或百分比？

财报和部分指标按源原值返回。单位或缩放没有完成认证时，系统不会自行换算；空值也不会补成0。

为什么 CSV 点下载没有反应？

如果内置浏览器提示下载停止，请使用电脑上的 Chrome 或 Safari 打开同一结果页再下载。此前服务器生成与外部浏览器保存链路已验证。

健康检查显示“未就绪”是否代表服务坏了？

健康状态记录当前 Gateway 进程实际读通过哪些能力。刚启动且尚未执行取数时可能显示未就绪；配置启用、当前进程读通和历史完整性是不同事实。

可以把账号、密码或数据库连接发给智能体吗？

不可以。不要在聊天中发送数据库凭据、Token、私钥或连接串，也不要要求系统生成带真实凭据的可运行代码。
